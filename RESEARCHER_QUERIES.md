## Enhanced Features

The enhanced data extraction now includes:

1. **Layer-specific analysis**: Surface (0-100m), Intermediate (100-500m), Deep (>500m)
2. **Statistical summaries**: Min, max, mean, std for all parameters
3. **Profile characteristics**: Vertical distribution with depth context
4. **Metadata extraction**: Platform info, data mode, cycle number
5. **Comprehensive coverage**: All standard Argo parameters

## Usage

Simply ask questions like:
- "What is the temperature profile?"
- "Show me salinity at different depths"
- "What are the oceanographic conditions?"
- "Describe the vertical structure of the ocean at this location"

The system will provide detailed, grounded answers based on the actual Argo data extracted from the NetCDF files.
